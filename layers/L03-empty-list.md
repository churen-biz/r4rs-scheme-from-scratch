# L03 — 空表 `()`

## 目标

增加立即数空表：源程序里的 `()` 或 `'()`（本层尚未有 `quote` 时，测试驱动喂已经 `read` 出来的空表对象）。编码 `EMPTY_LIST = 0x3F`。`rt_print` 打印 `()`。

本层范围之外：`cons`、`quote` 语法、`null?`（L05）、非空列表打印。`'(1 . 2)` 必须仍被前端拒绝。

## 原理

空表是一个**唯一**的立即数，不是堆上的哨兵结点。这样 `null?` 以后是一次满字比较，`cons` 不必分配「空」。R4RS 里 `'()` 与 `#f` 是不同对象——编码也必须不同（`0x3F` vs `0x2F`）。

低 8 位：`0x3F = 0b00111111`，低 3 位 `111`，落入立即数族，与 pair 指针标签 `001` 不冲突。

### 前端

宿主 `read` 读 `()` 得到空表。识别：

```scheme
(define EMPTY_LIST #x3F)

(define (expr->ir expr)
  (cond
    ((null? expr) `(imm ,EMPTY_LIST))
    ((eq? expr #t) `(imm ,BOOL_T))
    ((eq? expr #f) `(imm ,BOOL_F))
    ((fixnum-range? expr) `(imm ,(* expr 4)))
    (else (error "L03: bad literal" expr))))
```

注意：`(null? expr)` 必须在「把它当 pair 的字面量去递归编译」之前。本层没有 pair 字面量，`else` 直接 error 即可。

是否接受 `'()`：若驱动用 `read`，文件内容 `'()` 读出来是 `(quote ())` 这个 list，**不是**空表。本层没有 `quote`。测例文件请写 `()` 而不是 `'()`。若你提前把 `(quote x)` 展开成 `x` 且 `x` 是空表，也可以；须在本层文档实现注释里写「接受 quote 空表作为语法糖，其它 quote 仍报错」。推荐：**只接受 `()`**，quote 留到以后。

### 打印

```
EMPTY_LIST = 0x3F
_rt_print 增加：若 x == EMPTY_LIST，SYS_write "()\n"
```

插在布尔判断旁边。满字比较。

## 与上一层的差异

只多一个立即数常量与一条打印分支。不改标签体系、不改 `emit-imm`。

## 代码骨架

编译器与 `runtime.s` 注释各写一份：

```
EMPTY_LIST = 0x3F   ; 63
```

无新汇编模式。

## 测例清单

上一层全部测例仍须通过。

1. `()` → `()`
2. `#f` → `#f`（回归：空表不是假值的打印形式）
3. `0` → `0`
4. `#t` → `#t`
5. 输入 `'()`：若未实现 quote，编译期错误；若实现了「只展开空 quote」，→ `()`。在测例说明里锁定你的选择。推荐期望：编译期错误，避免 L41 之前出现半套 quote。
6. 输入 `(1 2)`：编译期错误（还没有 pair 常量）。

## 验收标准

- `()` 打印恰好 `()\n`。
- `#f` 与 `()` 输出不同。
- 未出现堆分配（本层 `HP` 仍可未使用）。

## 常见坑

- **测例写成 `'()` 却用 `read`**：得到 `(quote ())`，前端进 `else` 报错，误以为空表坏了。
- **打印 `nil` 或 `null`**：按 Scheme。
- **把空表放堆上**：浪费且让以后 `eq?` 对两个「空表」可能失败。必须是立即数。
