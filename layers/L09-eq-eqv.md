# L09 — 立即数上的 `eq?` 与 `eqv?`

## 目标

增加 `eq?` 与 `eqv?`。本层操作数只能是 **立即数**（fixnum、`#t`、`#f`、`()`、char）以及由已有原语算出的立即数结果。两个原语都实现为 **64 位机器字的位型相等**，结果为 `#t` 或 `#f`。

本层范围之外：堆对象（pair / vector / string / box / 符号 / 闭包——L13 起才有 pair）。用户语法 `quote` 的非空列表。`equal?`（结构递归，远晚于本层）。运行时类型分派（不必判断「是不是数字再改用 `=`」）。

## 原理

### R4RS 在立即数上的收缩

R4RS 里 `eq?` 对两个 fixnum 是否必须为真是实现可选项；`eqv?` 对两个相同的精确数字、两个相同字符、两个相同布尔则 **必须** 为真。本教程锁定：

```
对任意两个立即数 x、y：
  (eq?  x y)  ⇔  (eqv? x y)  ⇔  tagged_word(x) == tagged_word(y)
```

这比 R4RS 对 `eq?` 更强（同一 fixnum 位型必 `eq?`），是合法实现，且与「一个值一个 64 位字」的表示一致。

`#t` 与 `#f` 位型不同（`0x6F` vs `0x2F`）。`0` 的标签是 `0`，与 `#f` 的 `0x2F` 不同，因此 `(eq? 0 #f)` 为 `#f`——这是 Scheme 不是 C。`()` 是 `0x3F`，与 `#f` 也不同。`#\A` 的字是 `(65<<8)|0x0F`，与 fixnum `65`（`65<<2`）位型不同，故 `(eq? #\A 65)` 为 `#f`。

### 以后堆对象会怎样（现在不实现，只把合同写死）

位型相等 **就是** 指针身份：两个 pair 的 tagged 指针相等当且仅当它们是同一个堆对象。所以 `eq?` 的机器序列在 L13 之后 **不必改**。本层不测 `cons`，是因为还没有堆，不是因为以后要换算法。

`eqv?` 在 R4RS 里对 pair 也与 `eq?` 相同（不递归进 `car`/`cdr`）。真正分道的是以后可能出现的 bignum：两个位型不同的堆数字可能 `=` 但不必 `eq?`。L53 再打开这条缝。**本层 `eqv?` 与 `eq?` 发同一段代码。**

建议前端仍降成两个名字：

```
(prim eq?  Ir Ir)
(prim eqv? Ir Ir)
```

后端两个名字走同一 `emit-cmp-bool "eq"`。不要在前端把 `eqv?` 改写成 `eq?` 之后丢掉名字——L53 若要拆开，分派表还在。

### 求值与栈

与 `fx=` 完全相同的二元协议：左值 `str` 到 `[fp, #si]`，右值在 `x0`，`ldr` 到 `x9`，`cmp x9, x0`，物化 `#t`/`#f`。左到右。嵌套允许：`(eq? (fxadd1 1) 2)`、`(eq? (not #t) #f)`。

与 `fx=` 的唯一语义差别：`fx=` 的合同操作数是 fixnum；`eq?` 的合同操作数是任意立即数。实现上都是满字 `cmp`，所以对两个 fixnum，`(eq? a b)` 与 `(fx= a b)` 本层结果相同。保留两个原语：用户语法不同，L08 测例继续用 `fx=`。

### 不是 `fx=` 的地方

- `(eq? #t #t)` 合法且为 `#t`；`(fx= #t #t)` 本层仍属「非 fixnum 操作数，不定义」，不要用它当测例。
- `(eq? 0 #f)` 为 `#f`；没有对应的合法 `fx=` 测例。

IR 不引入新节点类型。arity 必须为 2。

## 与上一层的差异

- 新原语 `eq?` `eqv?`；比较的是任意立即数，不只是 fixnum。
- 机器序列可与 `fx=` 共享（满字相等 → 布尔）。
- 不改标签、不改栈帧、不改 `rt_print`。
- 文档上第一次明确：**指针身份 = 带标签字相等**；为 L13 的 `cons` 铺语义，本层仍无堆。

## 代码骨架

### 可移植：前端

```scheme
(define (eq-prim? name)
  (memq name '(eq? eqv?)))

;; expr->ir：
((and (pair? expr) (eq-prim? (car expr)))
 (unless (length=? expr 3)
   (error "L09: eq arity" expr))
 `(prim ,(car expr)
        ,(expr->ir (cadr expr))
        ,(expr->ir (caddr expr))))
```

源程序里的 `#t`/`#f` 仍按对象识别，与生成 IR 的 `eq?` 原语不是一回事。不要把源程序里的 `eq?` 调用在编译期折叠掉——本层要发出运行时 `cmp`，嵌套原语的结果不是字面量。常量折叠是优化，本层范围之外；测例含 `(eq? (fxadd1 1) 2)`，折叠或不折叠输出相同，但骨架按「总是运行时比较」写更简单。

### aarch64-apple：与 `fx=` 同体

```scheme
;; 在 emit-binop-body 的 case 中：
((eq?)  (emit-cmp-bool "eq"))
((eqv?) (emit-cmp-bool "eq"))
```

`emit-cmp-bool` 即 L08 的那段 `cmp x9, x0` + `csel` 到 `0x6F`/`0x2F`。不要对 `eq?` 去标签，不要只比低 8 位（否则不同立即数族可能碰撞）。

满字比较已覆盖：

| 左 | 右 | 位型 | 结果 |
|----|----|------|------|
| `0` | `#f` | `0` vs `0x2F` | `#f` |
| `()` | `#f` | `0x3F` vs `0x2F` | `#f` |
| `#\A` | `65` | `0x410F` vs `260` | `#f` |
| `#t` | `#t` | `0x6F` vs `0x6F` | `#t` |

`#\A`：`(65 << 8) | 0x0F = 0x410F`。fixnum `65`：`65 << 2 = 260 = 0x104`。

临时 `x9`/`x10`，不用 `x18`。

## 测例清单

上一层全部测例仍须通过。

1. `(eq? 1 1)` → `#t`
2. `(eq? 1 2)` → `#f`
3. `(eq? #t #t)` → `#t`；`(eq? #f #f)` → `#t`；`(eq? #t #f)` → `#f`
4. `(eq? 0 #f)` → `#f`（零不是假；位型不同）
5. `(eq? () ())` → `#t`；`(eq? () #f)` → `#f`
6. `(eq? #\A #\A)` → `#t`；`(eq? #\A #\B)` → `#f`
7. `(eq? #\A 65)` → `#f`（字符与同码点 fixnum 不是同一立即数）
8. `(eq? (fxadd1 1) 2)` → `#t`；`(eq? (not #t) #f)` → `#t`
9. `(eq? (fx+ 1 2) (fx* 1 3))` → `#t`
10. `(eqv? 1 1)` → `#t`；`(eqv? #f 0)` → `#f`（本层与 `eq?` 同结果）
11. `(eqv? #\nul 0)` → `#f`；`(eqv? (char->fixnum #\nul) 0)` → `#t`
12. `(not (eq? 1 1))` → `#f`
13. `(eq? -1 -1)` → `#t`；`(eq? -1 1)` → `#f`
14. `(eq?)` / `(eq? 1)` / `(eq? 1 2 3)`：编译期 arity 错误。

## 验收标准

- 测例 1–13 输出 `#t\n` 或 `#f\n`。
- `(eq? 0 #f)`、`(eq? () #f)`、`(eq? #\A 65)` 均为 `#f`：证明是满字位型比较，不是「假值等价」或「码点数值比较」。
- `eqv?` 与 `eq?` 在本层全部立即数测例上同结果；`.s` 中两段序列可以相同。
- 未分配堆、未调用 C。`eq?` 不得变成对 `rt_eq` 的 `bl`。
- 文档与实现一致：以后 pair 的 `eq?` 仍是这条 `cmp`（指针身份），本层只是没有 pair 测例。

## 常见坑

- **按 Scheme 假值来「相等」**：把 `0`、`()`、`#f` 当成一类。`eq?` 不是 `if` 的否定。
- **只比低 8 位**：fixnum `0x2F<<2` 之类以后若出现会撞；现在也会让某些字符与立即数族纠缠。满字 `cmp`。
- **对 fixnum 去标签再比、对布尔满字比**：两套路径。立即数合同就是一个字，一套路径。
- **在编译期折叠** `(eq? (fxadd1 1) 2)`：若你的 `expr->ir` 没真正递归降原语，会编译期错或发出错误 IR。先求值两侧再 `cmp`。
- **实现成 `fx=` 却拒绝非 fixnum 字面量**：`(eq? #t #t)` 必须过。
- **提前做 `equal?`**：不要递归进尚未存在的 pair。
